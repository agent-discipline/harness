### 잡지 못하는 것 (이 방어선의 한계)

- **표 어디에도 없는 요구**: 대조 파일의 "병합 때 생길 빠뜨림"(다른 갈래의 새 파일) · 문서의 어긋남 아홉은 task 의 요구 줄이 아니다.
- **채운 칸이 틀린 경우**: 메인이 엉뚱한 file:line 으로 칸을 채우면 표는 차 보인다. 큰 표만 워커가 다시 맞춘다.
- **요구를 잘못된 task 에 배정한 경우**: 받는 task 의 표에 옮기는 것까지는 하지만, 받는 task 가 명세에 없으면 "후보"로 새어 나갈 수 있다 — 그것을 §4 로 묻게 한 것이 막는 길이다.
- **절차 규칙의 고유 한계**: 훅이 보지 않는다. 같은 "개발 자세" 줄의 "task 로 나눈다"도 상시 주입인데 지켜지지 않았다(incident 4절).
