# korean-wording.md — 한국어 문서의 낱말 (조건부)

> 트리거: 사람이 읽을 한국어 문서(README, ADR 본문, 해설, 보고, 포트폴리오)를 쓰거나 고칠 때. 작업 원본(명세서, log, 측정 원본)은 대상이 아니다.
> 정본: `agent-discipline/rules`의 `writing/principles.md` "낱말" 절(규칙 19~26)과 `writing/wording-table.md`(사례 대장). 이 문서는 그 요약이고, 둘이 다르면 rules가 이긴다.

## 1. 기준

같은 일을 하는 사람이 말로 설명할 때 실제로 쓰는 낱말을 쓴다.

## 2. 규칙

1. 영어 개념을 순우리말로 새로 지어 옮기지 않는다. 지어낸 말은 독자가 원래 영어로 되돌려야 읽힌다.
2. 통용되는 외래어는 한글 표기로 쓴다(베이스라인, 스파이크, 테일 레이턴시, 폴백).
3. 이미 자리 잡은 한국어 용어는 바꾸지 않는다(대조군, 임계 구역, 오탐, 정합성, 처리량).
4. 현업에서 영어 표기 그대로 쓰는 말은 영어로 쓴다(prod, dev, yml, upsert, flush). 한글로 음차하거나 풀어 옮기지 않는다. 코드 식별자, 설정 키, 명령, 파일 확장자는 원문 표기를 바꾸지 않는다.
5. 낯선 용어는 처음 나온 자리에서 원어를 한 번 함께 적고, 그 뒤로는 한 낱말만 쓴다.
6. 같은 개념은 처음 정한 표기 하나로 끝까지 쓴다. 첫 등장의 원어 병기(규칙 5)와 코드 식별자, 설정 키(규칙 4)는 예외다.
7. 영어 표현을 낱말 단위로 직역한 은유를 쓰지 않는다. 뜻을 풀어 평범한 말로 쓴다.
8. 동작을 한자어 명사로 뭉치지 않는다("구현하였으며", "영속화하여", "체계를 구축"). 누가 무엇을 했는지 동사로 쓴다.
9. 작업하며 붙인 줄임 이름(A안, C, ①, 손잡이 같은 내부 별명)은 독자용 문서에 그대로 내보내지 않는다. 뜻을 풀어 쓰거나 첫 등장에 정의한다.

## 3. 자주 나온 꼴

| 쓰지 않는 말 | 원래 개념 | 쓰는 말 |
|---|---|---|
| 꼬리 지연, 튐 | tail latency, spike | 테일 레이턴시, 스파이크 |
| 기준선, 판정기 | baseline, oracle | 베이스라인, 정합성 검증기 |
| 벽, 무너짐 | throughput cliff | 처리량 급락 |
| 어긋남, 대조, 쌍 | drift, reconcile, key | 불일치, 보정 배치, 키 |
| 안전망, 한 바퀴, 훑다 | fallback scan, full scan | 폴백 스캔, 풀 스캔 1회, 스캔하다 |
| 손잡이 | optional setting | 설정 옵션 |
| 이긴 쪽, 진 쪽 | winner, loser | 성공한 요청, 실패한 요청 |
| 강하게 지지, 오염, 무음 실패 | strongly supports, contamination, silent failure | 유력한 원인, 측정 노이즈, 조용한 실패 |
| 지배적이다, 평평했다, 귀속 | dominant, flat, attribute | 대부분을 차지한다, 차이가 없었다, 무엇 때문인지 |
| 구현하였으며, 가시화, 체득, 도출, 수립 | (보고서 말투) | 했습니다, 볼 수 있게, 배웠습니다, 정했습니다 |

## 4. 판정

1. 다 쓴 뒤 `wording-table.md` 왼쪽 열 낱말로 문서를 검색한다. 걸린 곳마다 뜻과 제외 대상(5절)을 확인하고, 표의 뜻으로 쓰인 곳만 고친다.
2. 원래 영어 낱말을 떠올려야 뜻이 잡히는 낱말이 남았는가. 남았으면 고치고, 표에 없던 말이면 rules의 표에 한 줄을 더한다.
3. 고르기 어려우면 두 가지를 확인한다. 동료에게 말로 설명할 때 이 낱말을 쓰는가. 이 낱말로 검색하면 같은 뜻의 글이 나오는가.

## 5. 주의

- 같은 낱말이 여러 뜻으로 쓰이면 일괄 치환하지 않는다(실측: "대조"가 보정, 비교, 대조군, 양성 대조 네 뜻으로 쓰임).
- 글을 쓴 모델에게 같은 글을 검토시키면 자기 말투를 자연스럽다고 읽는다(실측 2026-11-18, 사용자 관찰). 검색은 표로 하고, 표를 키우는 검토는 사람이나 다른 모델이 한다.
- 사용자 발언 인용, 커밋 메시지, 로그 문자열은 고치지 않는다.
